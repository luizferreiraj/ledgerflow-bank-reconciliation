Esta página precisa do servidor

Você abriu o index.html como arquivo. A bancada não é uma página estática — ela é um programa que lê os PDFs e guarda os dados. Sem ele no ar, esta tela não funciona.

Feche esta aba e rode no terminal:

cd bank-statement-reconciler
./.venv/bin/workbench

Ele abre o navegador sozinho em http://127.0.0.1:8000. O endereço tem que começar com http:// — se aparecer Arquivo ou file://, é esta tela de novo. Deixe o terminal aberto enquanto estiver usando.
